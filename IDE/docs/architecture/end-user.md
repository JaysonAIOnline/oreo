# End users never see a terminal

Builders compile GraphLang.
People use a window: speak, hear, tap Yes, draw a line.

What they see
- The picture of their program
- GraphLang talking
- A Yes button when something is missing

What they never see
- A shell
- Cypher
- Intent JSON
- pip, Python, Bolt URIs

Builder view stays folded at the bottom for us.
The start surface is `Open GraphLang.py` / the browser window it opens.
